6.1 Automated Systems

An automated system performs actions without interaction with humans. They are used in small systems such as heating or air-conditioning in buildings, all the way up to flying aeroplanes and building cars.

Features of Automated Systems

An automated system usually has the following features:

  • Sensors — to measure the environment (e.g. temperature sensor, light sensor, pH sensor, infrared sensor, pressure sensor).
  • Microprocessor — to process data from the sensors and determine if an action needs to be taken.
  • Actuators — to create a movement or perform an action (e.g. open a door, turn on heating).

How Automated Systems Work

  1. Sensor reads the environment — sensors detect real-world analogue data (e.g. temperature 23.5 °C).
  2. Analogue-to-digital conversion — the sensor sends analogue data to an analogue-to-digital converter (ADC) because the microprocessor only understands binary (digital) data.
  3. Data sent to microprocessor — the digital data is transmitted to the microprocessor for processing.
  4. Comparison with stored values — the microprocessor compares the received data with pre-stored values or thresholds. These could be a single value, several values (min/max range), or a whole range.
  5. Decision — if the data is outside the stored range, the microprocessor sends a signal to the actuator to perform an action (e.g. turn on heating, open doors).
  6. Continuous loop — the whole process repeats until the system is turned off.

Flowchart description (Figure 6.2): START → Sensor reads environment → Data is converted to digital → Data is sent to microprocessor → Data compared to stored value/values → Decision: Is data in range? If YES, loop back to sensor reads. If NO, send signal to actuator to perform action, then loop back.

Control and Monitoring Systems

When considering a control or monitoring system, think in terms of Input → Process → Output:

  • Input: The data from the sensors (e.g. pressure sensor detects a person, infrared sensor detects movement).
  • Process: Analogue data converted to digital; microprocessor compares received data with stored values and determines the action.
  • Output: Signal sent to actuator to perform the required action (e.g. open a door for 5 seconds, reset timer if another person detected).

Automation in Context — Benefits and Drawbacks

When evaluating the use of automation, consider these factors:

Factor Benefit Drawback
Initial cost Long-term savings possible High upfront cost for equipment, software, and programming
Running cost Fewer employees needed long-term Maintenance and electricity costs
Safety Monitors environment continuously; reduces human error in dangerous tasks If hacked or programming errors occur, could cause harm
Jobs New maintenance/programming roles created Replaces existing human jobs
Continuous operation Works 24/7 without rest or breaks Requires maintenance schedules
Precision No human errors; consistent quality Dependent on correct programming

Example Contexts:

Car Manufacturing (Industry):

  • High initial cost for robots and software
  • Running costs offset by fewer employees
  • Safer — robots monitor environment and stop if danger detected
  • Some jobs lost but new maintenance roles created
  • Continuous 24/7 operation means more cars built
  • High precision with fewer faulty products

Nuclear Power Plant (Science):

  • High initial cost for devices and system development
  • Lower running costs with fewer people, though maintenance is expensive
  • Safer — less human error, people removed from dangerous areas
  • Some jobs replaced but new system maintenance roles created
  • Critical for continuous 24/7 monitoring without fatigue
  • High precision essential in this high-risk scenario

Greenhouse (Agriculture):

  • Moderate initial cost for installation and programming
  • Low running cost — small system with modest electricity needs
  • Safety less relevant as it is not a dangerous process
  • Few jobs replaced as not many people monitored conditions
  • Allows instant adaptation when conditions change
  • More accurate readings enable instant adjustments

6.2 Robotics

What Are Robots?

A robot is a mechanical device that performs an action, usually an action that a human would perform. Robotics is the area that covers the design, construction, and operation of robots.

A robot can be controlled by a person, automated, or a mixture of both. Examples include drones (controlled by a person or programmed) and manufacturing machines in factories.

Characteristics of a Robot

Robots have the following features:

  1. Mechanical structure or framework — the physical body of the robot.
  2. Electrical components including:
  • Sensors — to record the environment (e.g. position of a component being built)
  • Microprocessors — to take readings from sensors and decide the action to perform
  • Actuators — to make the robot move
  1. Programmable — a program can be written for the robot to follow.

6.3 Robots in Context

Robots in Medicine

  • Robot nurses can move around hospitals to visit and interact with patients, saving doctors and nurses time.
  • Remote surgery — a surgeon on the other side of the world can control a robot performing an operation. This means patients do not have to wait for specialists, and specialists are not required in every hospital.
  • Drawbacks: Programming errors or hacking could cause harm. If a surgeon is controlling remotely and the network connection is lost, the procedure stops. Backup systems must be in place.

Robots in Agriculture

  • Automated tractors use satellites and satellite navigation to guide their movements, allowing farmers to focus on other tasks.
  • Robots can plant seeds, remove weeds, check and adjust growing environments — operating 24 hours a day, 7 days a week versus 8 hours for a human worker.
  • Used for repetitive tasks — high upfront cost and maintenance required, but may replace workers who would otherwise perform these tasks.

Robots in Transport

  • Self-driving cars read their environment and move accordingly. They could improve safety because they react faster than humans, but have high upfront cost and security risks if someone accesses and changes the programming.
  • Factory transport robots move boxes of product to lorries. Completely automated, keeping people away from dangerous movements. They replace jobs but also create new maintenance roles.

Robots in Industry

  • Factories can be completely automated with robots on production lines, each performing a specific role (e.g. car assembly).
  • Robots run all day, every day, with no need for rest. They are more precise and not prone to human error.
  • However, workers lose their jobs (though new maintenance roles are created), and the initial cost is very large.
  • Robots can manage packing (e.g. putting biscuits into boxes), testing products (e.g. checking temperatures from ovens), and performing minute precision tasks (e.g. building circuits).

Robots in Entertainment

  • Robot toys such as robot dogs allow people to interact with technology.
  • Educational robots — children can build robots and program them to perform specific functions, learning how robots work and being introduced to programming.

Robots in Domestic Settings

  • Robot vacuum cleaners navigate rooms, detect obstacles, and change direction. They save people time but need monitoring and cannot handle stairs.
  • Robot lawnmowers monitor the area being mowed to ensure no spaces are missed.
  • Security robots can patrol an area, record video, detect motion or sound, and alert if an abnormality is detected.

6.4 Artificial Intelligence

The Turing Test

Alan Turing developed a test in 1950, called the Turing Test, to assess whether a computer can display intelligence. It involves a person holding a conversation with a computer program and another person. If the person cannot determine which is the computer and which is the human, the computer has passed the Turing Test. Some argue this does not truly demonstrate intelligence as the computer is still following pre-written rules.

What Is Artificial Intelligence?

Artificial intelligence (AI) is the development of programs to simulate human behaviour. There is a broad range of areas within AI:

  • Image recognition — identifying objects or people in an image.
  • Speech recognition — identifying words spoken and storing them.
  • Natural language processing — receiving commands or instructions not in a set format and performing the required response.
  • Computer games — moving elements or characters independently based on the environment.
  • Diagnosis systems — for example, medical diagnosis.

Components of AI

Artificial intelligence programs can be simplified to four key features:

  1. Collection of data — a program needs data input, which might come from a user (e.g. speech recognition) or from sensors (e.g. infrared sensors for a robot to determine position and obstacles).
  2. A set of programmed rules — stored for the program to make decisions. For example, a rule that if an object is in front of the sensor, turn to the right.
  3. The ability to reason — using logic to develop facts from rules. For example: All dogs eat meat. Fred is a dog. Therefore, Fred must eat meat.
  4. The ability to learn and adapt — a specialist area known as machine learning. Systems can be programmed to learn and change their own rules and logic through training (e.g. showing a system images of dogs and horses with labels so it learns to identify the animal).

Machine Learning

Machine learning is an area of artificial intelligence where a program can amend its own data and algorithms. Not all AI systems learn — some simply follow pre-programmed rules.

Supervised Learning

In supervised learning, the user tells the program what its data means. For example, in image recognition, the user provides labelled data (e.g. "this image shows a horse"). The system learns from these labelled examples.

Unsupervised Learning

In unsupervised learning, data is input and the program learns from the data without being told what it represents. An example is clustering — data is plotted on a graph, and the program identifies which items are close to each other. In image recognition, features in images are extracted and plotted, and the program groups images according to these features without human interaction.

Example — AI Chess Player: A computer game can use machine learning. An AI chess player alters its moves based on games it plays, simulating how a human learns. This could be supervised learning (told which moves are best) or unsupervised learning (playing other programs and changing its own rules without being told what to do).

Expert Systems

An expert system is a special type of system that attempts to emulate the expertise of a human, such as an engineer or doctor. The system asks the user questions to determine the solution or answer. Depending on each answer, the system asks a different question.

Example: A program to help fix a printer might ask: "Is there a green light on the printer?" If No → "Press the button to turn the printer on." If Yes → "Is there a red light underneath the paper picture?"

Four Key Features of an Expert System

  1. Knowledge base — a list of facts (e.g. there is a green light below the power symbol).
  2. Rule base — links the facts using logical rules (e.g. if the green light is on, then the printer has power).
  3. Inference engine — the part of the program that decides which question to ask next, or which answer to give. It applies the rules to the knowledge base.
  4. User interface — the part that outputs questions and statements to the user, and allows the user to enter data.

Context: Organisations use expert systems for troubleshooting repetitive problems without requiring a human expert (e.g. internet connection troubleshooting).

Chapter Summary

  • Robots can be found in medicine, agriculture, transport, industry, entertainment, and domestic settings, each with advantages and disadvantages.
  • Artificial intelligence is an area of computer science that aims to develop systems that mimic human intelligence.
  • Machine learning is one area of AI where a program can amend its own data and algorithms.

Key Formulas and Concepts

  1. Automated System Loop: Sensor reads → ADC converts analogue to digital → Microprocessor compares with stored values → Decision (in range: do nothing; out of range: signal actuator) → Loop back to sensor
  2. Input-Process-Output Model: All control and monitoring systems can be described as Input (sensor data) → Process (microprocessor comparison and decision) → Output (actuator action)
  3. Three Components of an Automated System: Sensors + Microprocessor + Actuators
  4. Three Characteristics of a Robot: Mechanical structure + Electrical components (sensors, microprocessors, actuators) + Programmable
  5. Four Components of AI: Collection of data + Programmed rules + Ability to reason + Ability to learn and adapt
  6. Four Components of an Expert System: Knowledge base + Rule base + Inference engine + User interface
  7. Two Types of Machine Learning: Supervised (labelled data provided by user) vs Unsupervised (program learns from unlabelled data)
  8. Six Factors for Evaluating Automation: Initial cost, Running cost, Safety, Replacing jobs, Continuous operation, Precision

Practice Questions

Question CS6.01

What type of data does a microprocessor process?

Answer: A microprocessor processes digital (binary) data. Analogue data from sensors must first be converted to digital data by an analogue-to-digital converter (ADC) before the microprocessor can process it.

Question CS6.02

What tasks does a sensor perform in an automated system?

Answer: A sensor reads/measures the environment (e.g. temperature, light, motion, pressure) and sends the data onwards to be processed. Sensors do not process data themselves — they only detect and transmit it.

Question CS6.03

Describe the process by which an automatic door opens when a person is detected.

Answer: A sensor (e.g. infrared or pressure sensor) detects a person. The analogue data is converted to digital by an ADC. The digital data is sent to the microprocessor, which compares it to stored values. If the data indicates a person is present (out of normal range), the microprocessor sends a signal to an actuator to open the door. The process repeats continuously.

Question CS6.04

An auto-pilot system will fly an aeroplane without input from a person. Identify two benefits and two drawbacks of using the auto-pilot.

Answer: Benefits: (1) The system can operate continuously without fatigue, reducing the risk of errors from tired pilots. (2) The system provides greater precision in maintaining altitude, speed, and direction. Drawbacks: (1) High initial cost for the auto-pilot system and software development. (2) If there are programming errors or the system is hacked, the consequences could be catastrophic.

Question CS6.05

A weather station records and stores data about the current weather conditions. Describe the advantages and disadvantages of using the automated system.

Answer: Advantages: The system can continuously monitor 24/7 without human attention, providing more frequent and accurate readings. It reduces human error in recording data. Disadvantages: The initial cost of sensors and equipment is high. If the system malfunctions, data may be lost or inaccurate without a person to notice. Maintenance is required, and the system cannot adapt to unusual conditions the way a human could.

Question CS6.06

Define the term robot.

Answer: A robot is a mechanical device that performs an action, usually an action that a human would perform. It can be controlled by a person, automated, or a mixture of both.

Question CS6.07

Identify three characteristics of a robot.

Answer: (1) A mechanical structure or framework — the physical body of the robot. (2) Electrical components including sensors, microprocessors, and actuators. (3) Programmable — a program can be written for the robot to follow.

Question CS6.08

Identify two ways robots can be used in industry.

Answer: (1) Robots can manage the packing of items, for example putting packets of biscuits into boxes. (2) Robots can perform tasks requiring exact precision, such as building electronic circuits or assembling components on a production line.

Question CS6.09

Give one benefit and one drawback of the use of domestic robots.

Answer: Benefit: Domestic robots such as robot vacuum cleaners save people time as they can perform household tasks automatically. Drawback: They still need monitoring, have limitations (e.g. cannot go up and down stairs), and have a high initial purchase cost.

Question CS6.10

Discuss the use of driverless cars.

Answer: Driverless (self-driving) cars are robots that read their environment using sensors and move accordingly. Benefits include improved safety as robots can react faster than humans, and they can operate continuously. Drawbacks include high upfront cost, security risks if someone accesses and changes the car's programming, the technology is still being developed and may not handle all scenarios, and ethical questions about decision-making in accidents.

Question CS6.11

Define the term artificial intelligence.

Answer: Artificial intelligence (AI) is the development of programs to simulate human behaviour. It encompasses areas such as image recognition, speech recognition, natural language processing, computer games, and diagnosis systems.

Question CS6.12

Describe what is meant by machine learning.

Answer: Machine learning is a specialist area of artificial intelligence where a program can learn, amend its own data and algorithms, and change its own rules and logic. It can be supervised (the user provides labelled training data) or unsupervised (the program learns patterns from unlabelled data on its own).

Question CS6.13

State the purpose of an expert system.

Answer: The purpose of an expert system is to emulate the expertise of a human specialist (such as a doctor or engineer) by asking the user a series of questions and using a knowledge base, rule base, and inference engine to determine the solution or answer.

Question CS6.14

Give two examples of where expert systems can be used.

Answer: (1) Troubleshooting technical problems, such as diagnosing why a printer is not working. (2) Medical diagnosis, where the system asks about symptoms and suggests possible conditions or treatments.

Question CS6.15

An expert system has an inference engine and interface. Describe the two other component parts of an expert system.

Answer: (1) Knowledge base — this is a list of facts stored in the system (e.g. there is a green light below the power symbol on a printer). (2) Rule base — this links the facts together using logical rules (e.g. if the green light is on, then the printer has power).

Question CS6.16

Describe how machine learning can be used to develop speech recognition systems.

Answer: In a speech recognition system, machine learning is used to train the program to recognise spoken words. In supervised learning, the system is provided with audio samples labelled with the correct words. The program learns the patterns and characteristics of different words. Over time, the system improves its accuracy by processing more data. In unsupervised learning, the system could identify patterns in audio data by clustering similar sounds together. The system adapts its algorithms to handle different accents, speeds, and pronunciations.

Question CS6.17

A car has a proximity detection system. If an object is within a set distance from the car, an alarm is sounded in the car. Describe how the automated system detects objects and alerts the driver.

Answer: A proximity sensor (such as an ultrasonic sensor) continuously measures the distance to nearby objects. The analogue data from the sensor is converted to digital by an ADC. The digital data is sent to the microprocessor, which compares the distance reading to a pre-stored threshold value. If the measured distance is less than (below) the stored threshold, the microprocessor determines the object is too close and sends a signal to an actuator (speaker/buzzer) to sound an alarm. This process repeats continuously while the system is active.

Question CS6.18

A factory that builds furniture is thinking about buying robots to replace the workers. Discuss the advantages and disadvantages of the factory replacing the workers with robots.

Answer: Advantages: (1) Robots can work continuously 24/7 without rest, increasing production output. (2) Robots are more precise and not prone to human error, resulting in fewer faulty products. (3) Robots can perform dangerous tasks, improving safety. Disadvantages: (1) The initial cost of purchasing robots and developing software is very large. (2) Existing workers will lose their jobs, though new maintenance and programming roles will be created with different skill sets. (3) Robots require ongoing maintenance, and if they break down, production stops until repaired.

Question CS6.19

Describe how artificial intelligence can be used to allow robots to react to their environment.

Answer: AI enables robots to use sensors to collect data about their environment (e.g. infrared sensors to detect obstacles, cameras for image recognition). The AI system has programmed rules that determine actions based on sensor input. It can reason — for example, if an obstacle is detected ahead, the rule says to turn. Advanced AI robots can use machine learning to improve over time, adapting their behaviour based on past experiences. For example, a robot filming animals could learn which movements are less likely to startle the animals.

Question CS6.20

Explain the difference between supervised and unsupervised machine learning, giving an example of each.

Answer: In supervised learning, the user provides the program with labelled training data, telling it what each piece of data represents. Example: showing the system images labelled as "dog" or "horse" so it learns to identify each animal. In unsupervised learning, data is input without labels and the program identifies patterns on its own. Example: clustering, where the program plots features of images on a graph and groups similar images together without being told what they are.

  2. Know the step-by-step process: sensor reads → ADC converts → microprocessor compares → actuator acts → loop repeats
  3. Be able to evaluate automation in different contexts using the six factors (initial cost, running cost, safety, jobs, continuous operation, precision)
  4. Know the three characteristics of a robot: mechanical structure, electrical components, and programmable
  5. Be able to discuss benefits and drawbacks of robots in specific contexts (medicine, agriculture, transport, industry, entertainment, domestic)
  6. Know the definition of AI and the four components: data collection, programmed rules, ability to reason, ability to learn/adapt
  7. Understand the difference between supervised and unsupervised machine learning with examples
  8. Know all four components of an expert system: knowledge base, rule base, inference engine, user interface
  9. Practice describing automated systems for unfamiliar scenarios using the Input-Process-Output model
  10. For extended-response questions, always give both advantages AND disadvantages with specific examples from the given context
